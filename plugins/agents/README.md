# Maniple for your coding agent

Maniple governs the applications that people across an organisation build with AI coding agents. This plugin lets you start and continue your Maniple applications from your coding agent, while your organisation's standards, approvals and budgets apply to the work.

It adds the skills `start`, `new` and `doctor`, and connects your coding agent to your organisation's own Maniple through its MCP server. You sign in to Maniple in your browser; the plugin holds no credentials and sends nothing anywhere but your organisation's Maniple.

## Setup

Install the plugin (see the repository's README for your agent), then ask the agent to use the Maniple `connect` skill with your Maniple address. It registers Maniple's MCP server with the agent's own command; then sign in when asked and use `start`.

Your platform team can tell you your Maniple address, for example `https://maniple.example.com`.
