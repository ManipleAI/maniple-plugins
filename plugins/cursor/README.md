# Maniple for Cursor

Maniple governs the applications that people across an organisation build with AI coding agents. This plugin lets you start and continue your Maniple applications from Cursor, while your organisation's standards, approvals and budgets apply to the work.

It adds the skills `start`, `new` and `doctor`, and connects Cursor to your organisation's own Maniple through its MCP server. You sign in to Maniple in your browser; the plugin holds no credentials and sends nothing anywhere but your organisation's Maniple.

## Setup

Your organisation's Cursor admin installs the plugin and sets `MANIPLE_URL` to your Maniple address (Cursor dashboard → Plugins → Configure). Then sign in to the maniple MCP server in Cursor Settings → MCP, and ask Cursor to start a Maniple application.

Your platform team can tell you your Maniple address, for example `https://maniple.example.com`.
